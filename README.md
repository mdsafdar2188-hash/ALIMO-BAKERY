# AliMo Bakery Website

## Run locally
1. Install Node.js 20+
2. Run `npm install`
3. Run `npm run dev`

## Deploy to Vercel
1. Upload this project to GitHub.
2. Import the repository into Vercel.
3. Vercel will detect Next.js automatically.
4. Click Deploy.

Before going live, replace the placeholder contact details and careers email.
